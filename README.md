# RAG-Based AI Teaching Assistant
IEEE Published Research | Kaggle Top 10% | GATE 2025

Ask a question about lecture videos and get a short answer that points to the exact video and minute to watch. It uses hybrid retrieval (dense + keyword), a cross-encoder reranker, a confidence gate that refuses questions the course does not cover, and a local LLM (LLaMA 3.2 through Ollama).

## What it does
- Turns lecture videos into searchable passages (Whisper speech-to-text, then passages of about 60 words with timestamps).
- Answers in 2 to 4 sentences and names the video, title and minute to watch, with the source passages shown below the answer.
- Says "the course does not seem to cover this" when the best passage is not relevant enough, instead of making something up.
- Everything runs locally (Ollama, FAISS, BM25); no paid API is needed.

## Data
18 lectures from the CodeWithHarry Sigma Web Development course (about 4.2 hours), transcribed with Whisper large-v2 (Hindi to English). That gives 7,252 transcript segments, which are merged into 1,222 overlapping passages of about 60 words. The lectures and their content belong to their creator; the transcripts here are used only to demonstrate the system.

## Architecture

```
Lecture videos -> FFmpeg audio -> Whisper large-v2 (Hindi -> English text with timestamps)
        |
7,252 short segments -> merged into 1,222 passages (~60 words, 20-word overlap)
        |
BGE-M3 embeddings (1024-dim) via Ollama
        |
   +----------------+----------------+
   |                                 |
FAISS IVF-Flat dense search    BM25 keyword search
   |                                 |
   +----------------+----------------+
                     |
       Reciprocal Rank Fusion (merges both ranked lists)
                     |
       Cross-encoder reranking (ms-marco-MiniLM-L-6-v2)
                     |
       Confidence gate: best reranker score below -7.44 -> "not covered"
                     |
           LLaMA 3.2 (via Ollama) writes the answer
                     |
        Answer + video + minute + source passages
```

## Results

Everything below was measured on 1,000 paraphrased questions generated by llama3.2 from random transcript segments (seed 42; `eval_questions.json` is included, so the numbers can be reproduced). A "strict hit" means the passage that contains the source segment is in the top 5.

### 1. Retrieval quality (passages of about 60 words)

| Setup | Recall@1 | Recall@5 | MRR@5 | Recall@5 incl. neighbours |
|---|---|---|---|---|
| Dense only (FAISS) | 33.0% | 54.7% | 0.411 | 56.1% |
| Keyword only (BM25) | 22.7% | 38.8% | 0.281 | 40.4% |
| Hybrid (FAISS + BM25 + RRF) | 31.7% | 55.7% | 0.401 | 57.1% |
| **Full pipeline (hybrid + rerank)** | **40.9%** | **64.0%** | **0.495** | **64.8%** |

The reranker is the largest gain (+8 points Recall@5 over hybrid). On the clearer questions (those that do not say "the author" or "this example", n=839) the full pipeline reaches 66.5% against 57.2% for dense only. The right *lecture* is among the top 5 results for 78.7% of questions (dense only: 73.0%); with only 18 lectures this is easier than it will be on a larger course.
